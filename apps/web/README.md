# Never Dice Web

Interface web em React para exibir rolagens de dados 3D recebidas via MQTT.

## Instalar

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- MQTT.js
- @3d-dice/dice-box-threejs
